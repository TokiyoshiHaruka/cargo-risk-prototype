# AI-Assisted Development

AI tools assisted with exploration, test-first implementation, code review,
and documentation drafts under human maintainer direction.

The maintainer owns the product hypothesis, simulation rules, visual direction,
security boundary, tests, and final publication decision. AI-generated output
was treated as a draft and verified locally before entering the repository.

No private credentials, personal data, external artwork, or proprietary game
assets were provided for this prototype.
